# Project Images

This folder contains visual materials used to present the Global Superstore Business Analysis project.

## Tableau Dashboard Preview

**File:** `tableau_dashboard.png`

A screenshot of the interactive Tableau dashboard displaying:

- Sales performance by category.
- Profit performance by category.
- Profit by sub-category.
- Tables sub-category discount versus profit analysis.
- Key performance indicators (KPIs), including total sales, total profit, and profit margin.

## Purpose

These visual assets provide a quick overview of the project findings and complement the detailed business analysis and documentation.
