# Project Documentation

This folder contains the formal documentation prepared for the Global Superstore Business Analysis and Data Quality Assessment project.

## Documents

### 1. Business Requirements Document (BRD)

**File:** `Superstore_BRD.pdf`

Defines the project objectives, business requirements, stakeholders, scope, key business questions, and expected deliverables.

### 2. Data Quality Test Cases

**File:** `Superstore_Data_Quality_Test_Cases.pdf`

Documents eight data quality checks (DQ-001 through DQ-008), including test objectives, validation results, and flagged findings.

### 3. Business Analysis Report

**File:** `Superstore_Business_Analysis_Report.pdf`

Presents the analysis findings, business insights, profitability trends, data quality observations, and recommendations.

## Project Scope

Together, these documents establish the business requirements, validate data reliability, and communicate findings to support business decision-making.
