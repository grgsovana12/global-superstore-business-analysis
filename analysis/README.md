# Data Analysis

This folder contains the Jupyter Notebook used to perform the Global Superstore business analysis and data quality assessment.

## Analysis Notebook

**Global_Superstore_Analysis.ipynb**

The notebook includes:

- Data loading and exploration using Python and Pandas.
- SQLite database creation and SQL queries.
- Data profiling and validation.
- Eight data quality checks (DQ-001 through DQ-008).
- Sales and profitability analysis.
- Product, category, and customer segment analysis.
- Discount and shipping cost analysis.
- Business findings and insights.

## Tools Used

- Python
- Pandas
- SQLite
- SQL
- Google Colab

## Dataset

The analysis uses the Global Superstore dataset, containing 51,290 records and 27 fields covering 2011–2014.
